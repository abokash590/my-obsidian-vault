```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> divisor_count_sieve(int n) {
    vector<int> cnt(n + 1, 0);

    for (int i = 1; i <= n; i++) {
        for (int j = i; j <= n; j += i) {
            cnt[j]++;
        }
    }
    return cnt;
}

int main() {
    int n;
    cin >> n;

    vector<int> cnt = divisor_count_sieve(n);

    for (int i = 1; i <= n; i++) {
        cout << i << " -> " << cnt[i] << "\n";
    }
}
```
## Complexity

| Operation                                           | Complexity                                       |
| --------------------------------------------------- | ------------------------------------------------ |
| Build divisor count for all numbers up to N (sieve) | O(N log N)                                       |
| Divisor count of a single x via trial division      | O(√x)                                            |
| Divisor count of a single x via prime factorization | O(√x) for factorization, then O(1) using formula |
