# Recursive → Iterative DP Convert করার Procedure
## 1. State চিনে নাও
Recursive function এর parameters গুলোই তোমার DP state। যেমন `solve(i, j)` হলে state হলো `(i, j)`।
## 2. DP Table বানাও
Parameters এর range অনুযায়ী array/table declare করো: `dp[n+1][m+1]` ইত্যাদি। Size = state এর সম্ভাব্য সব value cover করে এমন।
## 3. Base Case Identify করে Table-এ বসাও
Recursion-এ যেখানে সরাসরি return করতো (কোনো recursive call ছাড়া), সেটাই তোমার iterative table-এর initial values।
```cpp
if (i == n) return 0;
```

→

```cpp
dp[n][*] = 0;
```
## 4. Recurrence Relation বের করো
Recursive function-এর ভেতরে `solve(...)` call গুলো যেভাবে combine হচ্ছে (sum/min/max ইত্যাদি), সেটাই তোমার transition।
```cpp
return max(solve(i+1, j), val[i] + solve(i+1, j-1));
```

→

```cpp
dp[i][j] = max(dp[i+1][j], val[i] + dp[i+1][j-1]);
```
## 5. Dependency Direction বের করো (সবচেয়ে গুরুত্বপূর্ণ ধাপ)
`dp[i]` কি `dp[i+1]` এর উপর depend করে, নাকি `dp[i-1]` এর উপর? এটা দেখে ঠিক করবে loop কোন দিকে যাবে — base case থেকে answer-এর দিকে move করতে হবে।
- `solve(i)` → `solve(i+1)` কল করলে: loop চালাও `i = n` থেকে `0` পর্যন্ত (reverse)
- `solve(i)` → `solve(i-1)` কল করলে: loop চালাও `i = 0` থেকে `n` পর্যন্ত (forward)
## 6. Nested Loop লিখে Recurrence Apply করো

```cpp
for (int i = n; i >= 0; i--)
    for (int j = 0; j <= m; j++)
        dp[i][j] = /* same recurrence */;
```
## 7. Answer বের করো
Recursion যেখান থেকে শুরু হতো (যেমন `solve(0, m)`), সেটাই তোমার final answer: `dp[0][m]`।

---
## Quick Trick
Recursive memoized code হাতের কাছে থাকলে:
1. `solve(...)` কে `dp[...]` দিয়ে replace করো
2. Recursive call-গুলো remove করে সেই জায়গায় already-computed value বসাও
3. Base case-গুলোকে loop-এর initialization-এ পরিণত করো
4. Loop-এর direction ঠিক করো (dependency অনুযায়ী)
