### 1. Declaration & Initialization

|Syntax|Description|Time Complexity|
|:--|:--|:--|
|`unordered_set<int> us;`|Declares an empty unordered_set (Unsorted, hash-based)|$O(1)$|
|`unordered_set<int> us = {1, 5, 2};`|Initializes with values (Removes duplicates)|$O(N)$ Average|
|`unordered_set<int> us(v.begin(), v.end());`|Vector থেকে unique element নিয়ে unordered_set বানায়|$O(N)$ Average|
|`unordered_multiset<int> ums;`|Duplicate value রাখতে পারে (Unsorted, hash-based)|$O(1)$|

### 2. Input & Output (Insertion & Traversal)

|Task|Syntax|Time Complexity|
|:--|:--|:--|
|**Insert**|`us.insert(x);`|$O(1)$ Average, $O(N)$ Worst|
|**Traversal**|`for(auto x : us) cout << x << " ";`|$O(N)$|
|**Iterator Traversal**|`for(auto it = us.begin(); it != us.end(); ++it)`|$O(N)$|
|**Check Existence**|`if(us.count(x))` or `if(us.find(x) != us.end())`|$O(1)$ Average|

### 3. Access & Search (Properties)

|Syntax|Description|Time Complexity|
|:--|:--|:--|
|`us.size()`|Unique element সংখ্যা রিটার্ন করে|$O(1)$|
|`us.empty()`|Set খালি হলে true রিটার্ন করে|$O(1)$|
|`us.bucket_count()`|মোট bucket সংখ্যা রিটার্ন করে|$O(1)$|
|`us.load_factor()`|Average elements per bucket রিটার্ন করে|$O(1)$|

⚠️ **Note:** `unordered_set`-এ `*us.begin()` বা `*us.rbegin()` দিয়ে min/max পাওয়া যাবে **না**, কারণ এটা sorted না — কোনো নির্দিষ্ট order গ্যারান্টি নেই।

### 4. Push, Pop & Insert (Modification)

|Syntax|Description|Time Complexity|
|:--|:--|:--|
|`us.emplace(x);`|Element সরাসরি insert করে (insert থেকে দ্রুত)|$O(1)$ Average|
|`us.erase(x);`|নির্দিষ্ট value $x$ রিমুভ করে|$O(1)$ Average|
|`us.erase(it);`|Iterator position-এর element রিমুভ করে|$O(1)$ Average|
|`us.clear();`|সব element রিমুভ করে|$O(N)$|

### 5. No Range Search (Key Difference from `set`)

|Operation|Available in `unordered_set`?|কারণ|
|:--|:--|:--|
|`lower_bound(x)`|❌ Not available (member function হিসেবে)|Hash table sorted না, তাই ordering-based search সম্ভব না|
|`upper_bound(x)`|❌ Not available|একই কারণ|
|`equal_range(x)`|✅ Available, তবে শুধু x আছে কিনা সেটা চেক করার জন্য (range না)|Hash-based lookup|

---

### 💡 Important Patterns & Tips (My Recommendations)

১. **set vs unordered_set — কখন কোনটা?** যদি sorted order লাগে, বা lower_bound/upper_bound দরকার হয় → `set` ব্যবহার করুন। যদি শুধু fast existence check ($O(1)$ average) লাগে, order কোনো ব্যাপার না → `unordered_set` ব্যবহার করুন।

২. **Worst Case Warning:** `unordered_set`-এর operation গুলো average-এ $O(1)$ হলেও, hash collision বেশি হলে worst case-এ $O(N)$ পর্যন্ত হতে পারে (বিশেষত custom hash function ছাড়া pair/struct ব্যবহার করলে)। Competitive programming-এ anti-hash test case এড়াতে custom hash function ব্যবহার করা ভালো।

৩. **Global binary_search কখনো না:** `set`-এর মতোই, `unordered_set`-এও global `binary_search()` ব্যবহার করবেন না — এটা অর্থহীন কারণ elements sorted না। সবসময় `us.find(x)` বা `us.count(x)` ব্যবহার করুন।

৪. **Unique Elements from Vector (Fast, Unordered):** Order না লাগলে এটা `set` এর চেয়েও দ্রুত:

```cpp
unordered_set<int> us(v.begin(), v.end());
```

৫. **Iterator Invalidation:** `unordered_set`-এ insert করলে rehashing হতে পারে, যার ফলে existing iterator invalidate হয়ে যেতে পারে (তবে references/pointers সাধারণত valid থাকে)। Loop-এর ভেতরে insert করার সময় সতর্ক থাকুন।
