### 1. Declaration & Initialization

|Syntax|Description|Time Complexity|
|:--|:--|:--|
|`string s;`|Declares an empty string|$O(1)$|
|`string s = "hello";`|Initializes string with a value|$O(N)$|
|`string s(5, 'a');`|Initializes string with 5 copies of `'a'` → `"aaaaa"`|$O(N)$|
|`string s2(s1);`|Copy constructor (copies another string)|$O(N)$|
|`string s = s1 + s2;`|Concatenates two strings|$O(N)$|

### 2. Input & Output (Traversal)

|Task|Syntax|Time Complexity|
|:--|:--|:--|
|**Input (single word)**|`cin >> s;`|$O(N)$|
|**Input (with spaces)**|`getline(cin, s);`|$O(N)$|
|**Output**|`cout << s;`|$O(N)$|
|**Traversal (index)**|`for(int i = 0; i < s.size(); i++) cout << s[i];`|$O(N)$|
|**Traversal (range-based)**|`for(char c : s) cout << c;`|$O(N)$|
|**Iterator Traversal**|`for(auto it = s.begin(); it != s.end(); ++it)`|$O(N)$|

### 3. Access & Search (Properties)

|Syntax|Description|Time Complexity|
|:--|:--|:--|
|`s.size()` / `s.length()`|Returns number of characters|$O(1)$|
|`s.empty()`|Returns true if string is empty|$O(1)$|
|`s[i]` / `s.at(i)`|Access character at index $i$ (`.at()` করে bounds checking)|$O(1)$|
|`s.front()`|Access first character|$O(1)$|
|`s.back()`|Access last character|$O(1)$|
|`s.find(x)`|নির্দিষ্ট substring/char-এর প্রথম occurrence index রিটার্ন করে (না পেলে `string::npos`)|$O(N)$|
|`s.find(x, pos)`|`pos` index থেকে শুরু করে $x$ খোঁজে — প্রথম argument সবসময় খুঁজতে চাওয়া substring, দ্বিতীয়টা start position (উল্টো করলে compile error)|$O(N)$|
|`s.rfind(x)`|নির্দিষ্ট substring/char-এর **last** occurrence index রিটার্ন করে|$O(N)$|
|`s.substr(pos, len)`|index `pos` থেকে `len` length-এর substring রিটার্ন করে|$O(len)$|

### 4. Push, Pop & Insert (Modification)

|Syntax|Description|Time Complexity|
|:--|:--|:--|
|`s.push_back(c);`|শেষে একটা character যোগ করে|$O(1)$ Amortized|
|`s.pop_back();`|শেষের character রিমুভ করে|$O(1)$|
|`s.append(str);` / `s += str;`|শেষে string/char যোগ করে|$O(M)$ (M = added length)|
|`s.insert(pos, str);`|নির্দিষ্ট position-এ string insert করে|$O(N)$|
|`s.erase(pos, len);`|`pos` থেকে `len` length-এর character রিমুভ করে|$O(N)$|
|`s.replace(pos, len, str);`|নির্দিষ্ট অংশ replace করে নতুন string দিয়ে|$O(N)$|
|`s.clear();`|সব character রিমুভ করে|$O(N)$|

### 5. Sorting & Conversion

|Operation|Syntax|Time Complexity|
|:--|:--|:--|
|**Sort characters**|`sort(s.begin(), s.end());`|$O(N \log N)$|
|**Reverse**|`reverse(s.begin(), s.end());`|$O(N)$|
|**string → int**|`stoi(s);`|$O(N)$|
|**string → long long**|`stoll(s);`|$O(N)$|
|**string → double**|`stod(s);`|$O(N)$|
|**int/number → string**|`to_string(x);`|$O(digits)$|
|**Uppercase/Lowercase**|`transform(s.begin(), s.end(), s.begin(), ::toupper);`|$O(N)$|

### 💡 Important Patterns & Tips (My Recommendations)

১. **`s.find()` এর return type নিয়ে সাবধান:** `find()` না পেলে `string::npos` রিটার্ন করে, যেটা আসলে একটা বিশাল unsigned value (`-1` এর মতো)। তাই কখনো এভাবে চেক করবেন না:

```cpp
if(s.find(x) == -1) // ভুল!
```

সঠিকভাবে চেক করুন:

```cpp
if(s.find(x) == string::npos) // ঠিক
```

২. **String Concatenation Efficiency:** Loop-এর ভেতরে বারবার `s = s + c;` করলে প্রতিবার নতুন string তৈরি হয় ($O(N)$), ফলে total complexity $O(N^2)$ হয়ে যায়। এর বদলে `s.push_back(c)` বা `s += c` ব্যবহার করুন, যেটা amortized $O(1)$।

৩. **Passing string to function:** বড় string বারবার copy এড়াতে সবসময় `const string&` দিয়ে function-এ পাঠান:

```cpp
void func(const string &s) { ... } // copy হবে না, fast
```

৪. **Char Array vs String:** Competitive programming-এ `char arr[]` এর চেয়ে `string` ব্যবহার করাই ভালো, কারণ STL-এর built-in functions (`substr`, `find`, `erase` ইত্যাদি) সরাসরি ব্যবহার করা যায়, manual pointer handling লাগে না।

৫. **stringstream দিয়ে Split/Parse:** Space দিয়ে separated words আলাদা করতে `stringstream` খুব কাজের:

```cpp
#include <sstream>
stringstream ss(s);
string word;
while(ss >> word) {
    cout << word << endl; // প্রতিটা word আলাদা করে পাবেন
}
```

৬. **Palindrome Check (Common Pattern):**

```cpp
bool isPalindrome(string s) {
    string rev = s;
    reverse(rev.begin(), rev.end());
    return s == rev;
}
```
