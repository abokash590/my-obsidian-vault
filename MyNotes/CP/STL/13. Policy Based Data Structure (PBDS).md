### 1. Header & Initialization

⚠️ **Note:** PBDS standard C++ এর অংশ না — এটা GCC/g++ এর একটা extension। তাই শুধু GCC compiler-এ কাজ করবে (Codeforces, most online judges এ চলে, কিন্তু সব জায়গায় guaranteed না)।

```cpp
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>
using namespace __gnu_pbds;

template<typename T>
using ordered_set = tree<T, null_type, less<T>, rb_tree_tag, tree_order_statistics_node_update>;
```

|Template Parameter|Description|
|:--|:--|
|`T`|Key-এর data type (int, pair, etc.)|
|`null_type`|Value type — set-এর মতো শুধু key রাখতে চাইলে `null_type`, map-এর মতো value সহ রাখতে চাইলে data type দিন|
|`less<T>`|Comparator — ডুপ্লিকেট গ্রহণ করে **না** (Set এর মতো unique elements)|
|`less_equal<T>`|Comparator — ডুপ্লিকেট গ্রহণ করে (Multiset এর মতো), তবে নিচে ⚠️ note দেখুন|
|`rb_tree_tag`|Internally Red-Black Tree ব্যবহার করে|
|`tree_order_statistics_node_update`|Order-statistics ability (rank query) enable করে|

### 2. Basic Operations (Same as `set`)

| Task                | Syntax                               | Time Complexity |
| :------------------ | :----------------------------------- | :-------------- |
| **Insert**          | `st.insert(x);`                      | $O(\log N)$     |
| **Erase**           | `st.erase(x);`                       | $O(\log N)$     |
| **Check Existence** | `st.find(x) != st.end()`             | $O(\log N)$     |
| **Size**            | `st.size();`                         | $O(1)$          |
| **Traversal**       | `for(auto x : st) cout << x << " ";` | $O(N)$          |

### 3. Special Abilities (Order Statistics — PBDS-এর মূল সুবিধা)

| Syntax                 | Description                                                                                           | Time Complexity |
| :--------------------- | :---------------------------------------------------------------------------------------------------- | :-------------- |
| `st.order_of_key(x)`   | সেটে $x$ এর চেয়ে **strictly ছোট** কতগুলো element আছে তা রিটার্ন করে (0-indexed rank)                 | $O(\log N)$     |
| `*st.find_by_order(k)` | $k$-তম (0-indexed) index-এ থাকা value রিটার্ন করে — অর্থাৎ sorted order-এ $(k+1)$-তম smallest element | $O(\log N)$     |

**উদাহরণ:**

```cpp
ordered_set<int> st;
st.insert(5);
st.insert(1);
st.insert(3);
// sorted order: 1, 3, 5 (index: 0, 1, 2)

cout << st.order_of_key(3); // Output: 1 (কারণ 3 এর চেয়ে ছোট আছে শুধু 1টি: {1})
cout << *st.find_by_order(1); // Output: 3 (index 1 এ আছে 3)
```

---

### 💡 Important Patterns & Tips (My Recommendations)

১. **`order_of_key` দিয়ে "কতগুলো ছোট/বড়" বের করা:** $x$ এর চেয়ে ছোট কতগুলো element আছে সরাসরি পাওয়া যায়:

```cpp
int count_smaller = st.order_of_key(x);
```

$x$ এর চেয়ে ছোট বা সমান কতগুলো আছে জানতে:

```cpp
int count_smaller_equal = st.order_of_key(x + 1); // শুধু integer-এর জন্য কাজ করে
```

২. **`less_equal` দিয়ে Multiset বানালে সাবধান:** `less_equal<T>` ব্যবহার করে duplicate values রাখা গেলেও, `st.erase(x)` করলে ওই ভ্যালুর **সবগুলো** কপি একসাথে ডিলিট হয়ে যায় না — বরং internal tree structure-এ bug-prone আচরণ করে (find/erase ঠিকমতো কাজ নাও করতে পারে)। তাই duplicate handle করতে চাইলে সাধারণত values-এর সাথে একটা unique tiebreaker (যেমন index) জুড়ে `pair<T, int>` ব্যবহার করা হয়:

```cpp
tree<pair<int,int>, null_type, less<pair<int,int>>, rb_tree_tag, tree_order_statistics_node_update> st;
// insert করার সময়: st.insert({value, unique_id});
```

৩. **K-th Smallest/Largest বের করার সহজ Pattern:**

```cpp
// k-th smallest (1-indexed)
int kth_smallest = *st.find_by_order(k - 1);

// k-th largest (1-indexed)
int kth_largest = *st.find_by_order(st.size() - k);
```

৪. **Rank of an Element (কোনো element-এর position জানা):**

```cpp
int rank = st.order_of_key(x) + 1; // sorted order-এ x এর 1-indexed position
```

৫. **Compile করার সময়:** এই ফিচার ব্যবহার করতে সাধারণত extra flag লাগে না GCC-তে, তবে কিছু judge/environment-এ policy tree headers না পেলে GCC version আপডেট করা লাগতে পারে।
