# রিকার্সিভ DP থেকে আইটারেটিভ DP — সম্পূর্ণ ধারণা নোট

## পার্ট ১: প্রথমে মানসিকতা (mindset) টা ঠিক করো

রিকার্সিভ DP-তে আমরা কাজ করি **"উপর থেকে নিচে"** (Top-Down):

> "বড় প্রব্লেম সলভ করতে হলে, আগে ছোট প্রব্লেমগুলো সলভ করো, তারপর সেগুলো জোড়া দিয়ে বড় উত্তর বের করো।"

ফাংশন নিজেকে কল করে ছোট ভার্সনের উপর, যতক্ষণ না বেস কেসে পৌঁছায়। তারপর **রিটার্ন করতে করতে উপরে উঠে আসে**, উত্তর তৈরি হয়।

আইটারেটিভ DP-তে আমরা কাজ করি **"নিচ থেকে উপরে"** (Bottom-Up):

> "সবচেয়ে ছোট/সহজ প্রব্লেম (বেস কেস) টা আগেই ক্যালকুলেট করে রাখি, তারপর ধীরে ধীরে বড় প্রব্লেমের দিকে এগোই, আগে ক্যালকুলেট করা রেজাল্টগুলো ব্যবহার করে।"

কোনো ফাংশন কল থাকে না — শুধু একটা **অ্যারে (array)** থাকে, আর লুপ দিয়ে সেটা **ফিল আপ** করা হয়, ছোট ইনডেক্স থেকে বড় ইনডেক্সের দিকে।

**একলাইনে মনে রাখো:**

> রিকার্সিভ = প্রশ্ন করতে করতে নিচে যাওয়া, তারপর উত্তর নিয়ে উপরে ওঠা। আইটারেটিভ = আগে থেকে উত্তরগুলো বিল্ড করে রাখা, দরকার মতো তুলে নেওয়া।

## পার্ট ২: রিকার্সিভ থেকে আইটারেটিভে কনভার্ট করার সঠিক প্রসেস (৫টা ধাপ)

এই ৫টা ধাপ **সবসময়** ফলো করবা — যেকোনো রিকার্সিভ DP-কে আইটারেটিভে কনভার্ট করার জন্য:

### ধাপ ১ — স্টেট (state) টা কী, খুঁজে বের করো

রিকার্সিভ ফাংশনের **প্যারামিটার**গুলোই হলো "স্টেট"। যেমন:

cpp

```cpp
int solve(int i, int need)
```

এখানে স্টেট হলো `(i, need)` — দুইটা ভ্যারিয়েবল। এটা বুঝলে এই দুইটা ভ্যারিয়েবল দিয়েই একটা **টেবিল (array)** বানাতে হবে, যেখানে প্রতিটা `(i, need)` কম্বিনেশনের উত্তর স্টোর হবে।

### ধাপ ২ — বেস কেস (base case) টা কী, খুঁজে বের করো

রিকার্সিভ ফাংশনে সবচেয়ে ছোট/সহজ ইনপুটে কী রিটার্ন হয়, এটা দেখো:

cpp

```cpp
if(!need) return 1;
```

এটা বলে: `need=0` হলে উত্তর সবসময় `1`। এটা আমাদের টেবিলে **শুরুতেই বসিয়ে দিতে হবে** (ইনিশিয়ালাইজ করা)।

### ধাপ ৩ — রিকারেন্স (recurrence/transition) টা কী, খুঁজে বের করো

রিকার্সিভ কলগুলো দেখো — কীভাবে বড় স্টেট থেকে ছোট স্টেটে যাচ্ছে:

cpp

```cpp
cnt = solve(i+1, need);                    // না নিলে (don't take)
cnt = add(cnt, solve(i, need - v[i]));     // নিলে (take)
```

এটা বলে: `dp[i][need]` বের হয় `dp[i+1][need]` আর `dp[i][need-v[i]]` থেকে। এটাই আমাদের **ফরমুলা**, যেটা লুপে ব্যবহার করবো।

### ধাপ ৪ — কোন দিকে লুপ চালাতে হবে, এটা ঠিক করো (সবচেয়ে গুরুত্বপূর্ণ ধাপ)

এটা বুঝতে হবে: **উত্তর বের করতে যে জায়গার উপর ডিপেন্ড করে, সেই জায়গাটা আগে ক্যালকুলেট হয়ে থাকতে হবে।**

উপরের রিকারেন্স দেখো:

- `dp[i][need]` ডিপেন্ড করে `dp[i][need-v[i]]`-এর উপর — মানে **ছোট `need`** আগে লাগবে
- `dp[i][need]` ডিপেন্ড করে `dp[i+1][need]`-এর উপর — মানে **বড় `i`** আগে লাগবে

তাই লুপ চালাতে হবে:

- `need` : **ছোট থেকে বড়** দিকে (0 → sum)
- `i` : **বড় থেকে ছোট** দিকে (n → 0), অথবা সমতুল্যভাবে কয়েন-কে একবার করে প্রসেস করলে অর্ডার এমনিতেই ঠিক থাকে

(এটা প্রতিটা প্রব্লেমে আলাদা হবে — রিকারেন্স দেখে বুঝতে হবে কোন দিকে ডিপেন্ডেন্সি আছে)

### ধাপ ৫ — অ্যারে বানাও, বেস কেস বসাও, লুপ দিয়ে ফিল করো, উত্তর বের করো

cpp

```cpp
vector<int> dp(sum+1, 0);   // অ্যারে (টেবিল) বানানো
dp[0] = 1;                    // বেস কেস বসানো (ধাপ ২ থেকে)

for(...){                     // লুপ (ধাপ ৪-এর অর্ডার অনুযায়ী)
    dp[s] = add(dp[s], dp[s-v[i]]);   // রিকারেন্স অ্যাপ্লাই করা (ধাপ ৩ থেকে)
}

cout << dp[sum];              // উত্তর টেবিলের "অরিজিনাল কল"-এর জায়গায় পাওয়া যাবে
```

## পার্ট ৩: ছোট উদাহরণ দিয়ে প্র্যাকটিস — ফিবোনাচ্চি (Fibonacci)

আগে একটা খুব সিম্পল উদাহরণ দিয়ে প্রসেসটা হাতে-কলমে দেখি, তারপর কম্বিনেশনস II-তে যাবো।

### রিকার্সিভ ফিবোনাচ্চি:

cpp

```cpp
int fib(int n){
    if(n <= 1) return n;              // বেস কেস
    return fib(n-1) + fib(n-2);        // রিকারেন্স
}
```

**৫ ধাপ অ্যাপ্লাই করি:**

1. **স্টেট:** `n` (একটা ভ্যারিয়েবল)
2. **বেস কেস:** `n=0` → `0`, `n=1` → `1`
3. **রিকারেন্স:** `fib(n) = fib(n-1) + fib(n-2)`
4. **লুপের দিক:** `fib(n)` ডিপেন্ড করে ছোট `n-1, n-2`-এর উপর — তাই `n` **ছোট থেকে বড়** দিকে লুপ চলবে
5. **আইটারেটিভ কোড:**

cpp

```cpp
vector<int> dp(n+1);
dp[0] = 0;                  // বেস কেস
dp[1] = 1;                  // বেস কেস
for(int i = 2; i <= n; i++){
    dp[i] = dp[i-1] + dp[i-2];   // রিকারেন্স, লুপ দিয়ে
}
cout << dp[n];
```

দেখো — রিকার্সিভের **বেস কেস** আর **রিকারেন্স** টা **হুবহু একই থাকছে**, শুধু ফাংশন কলের বদলে **অ্যারে + লুপ** দিয়ে করা হচ্ছে।

## পার্ট ৪: এখন কম্বিনেশনস II — পুরো প্রসেস ধাপে ধাপে

### রিকার্সিভ ভার্সন (তুমি যা শিখেছো):

cpp

```cpp
int solve(int i, int need){
    if(!need) return 1;                        // বেস কেস
    if(i == n) return 0;                        // এক্সট্রা বেস কেস
    int cnt = solve(i+1, need);                  // না নিলে
    if(v[i] <= need)
        cnt = add(cnt, solve(i, need - v[i]));   // নিলে
    return cnt;
}
// কল করা হয়: solve(0, sum)
```

### ধাপ ১ — স্টেট

`(i, need)` — দুইটা ভ্যারিয়েবল, তাই **2D অ্যারে** লাগবে: `dp[i][need]`

### ধাপ ২ — বেস কেস

- `need == 0` → `1`
- `i == n` (আর `need != 0`) → `0` (এটা ডিফল্ট ভ্যালু দিয়েই হ্যান্ডেল হয়, কারণ আমরা 0 দিয়ে অ্যারে ফিল করবো)

### ধাপ ৩ — রিকারেন্স

```
dp[i][need] = dp[i+1][need]                      (না নিলে)
            + dp[i][need - v[i]]   (যদি v[i] <= need হয়)   (নিলে)
```

### ধাপ ৪ — লুপের দিক ঠিক করা

- `dp[i][need]` ডিপেন্ড করে `dp[i+1][need]`-এর উপর → **`i` বড় থেকে ছোট দিকে লুপ চলবে** (n-1 থেকে 0)
- `dp[i][need]` ডিপেন্ড করে `dp[i][need-v[i]]`-এর উপর (**একই `i`**, ছোট `need`) → `need` **ছোট থেকে বড়** দিকে লুপ চলবে

### ধাপ ৫ — সম্পূর্ণ আইটারেটিভ কোড

cpp

```cpp
vector<vector<int>> dp(n+1, vector<int>(sum+1, 0));

// বেস কেস বসানো
for(int i = 0; i <= n; i++) dp[i][0] = 1;   // need=0 হলে সবসময় 1 way

// লুপ: i কে উল্টা দিকে (n-1 থেকে 0), need কে সোজা দিকে (1 থেকে sum)
for(int i = n-1; i >= 0; i--){
    for(int need = 1; need <= sum; need++){
        dp[i][need] = dp[i+1][need];               // না নিলে
        if(v[i] <= need)
            dp[i][need] = add(dp[i][need], dp[i][need - v[i]]);  // নিলে
    }
}

cout << dp[0][sum];   // উত্তর, কারণ অরিজিনাল কল ছিল solve(0, sum)
```

**লক্ষ্য করো** — রিকার্সিভ ফাংশনের **প্রতিটা লাইন** এখন আইটারেটিভ কোডে **হুবহু একই জায়গায়** আছে, শুধু `solve(...)` কলের বদলে `dp[...]` অ্যারে অ্যাক্সেস হচ্ছে।

---

### অপটিমাইজ করা ভার্সন (1D অ্যারে — মেমরি কমে যায়)

যেহেতু `dp[i][...]` শুধু `dp[i+1][...]` আর **একই row** (`dp[i][...]`)-এর উপর ডিপেন্ড করে, তাই `i` কে সম্পূর্ণ বাদ দিয়ে একটা **1D অ্যারে** দিয়েও কাজ চলতে পারে (এটা একটা অ্যাডভান্সড অপটিমাইজেশন, আগে উপরের 2D ভার্সনটা বুঝলে তারপর এটা দেখো):

cpp

```cpp
vector<int> dp(sum+1, 0);
dp[0] = 1;

for(int i = 0; i < n; i++){              // প্রতিটা কয়েন একবার
    for(int s = v[i]; s <= sum; s++){    // sum ছোট থেকে বড়
        dp[s] = add(dp[s], dp[s-v[i]]);
    }
}
cout << dp[sum];
```

## পার্ট ৫: কমন মিসটেক চেকলিস্ট (এগুলো দেখে নিজেকে চেক করো)

|ভুল|ঠিক|
|---|---|
|লুপের দিক না ভেবে বসানো|আগে রিকারেন্স দেখে বুঝতে হবে কোনটা আগে লাগবে|
|বেস কেস অ্যারেতে বসাতে ভুলে যাওয়া|রিকার্সিভের বেস কেসটা **সবসময়** আগে অ্যারেতে বসাতে হবে|
|অ্যারের সাইজ ভুল দেওয়া (`n` না `n+1`)|স্টেটের ম্যাক্স ভ্যালু + 1 সাইজ দিতে হবে|
|অরিজিনাল কলটা কী ছিল (`solve(0,sum)`) — সেই জায়গা থেকে উত্তর না নেওয়া|উত্তর শেষে ঠিক ওই সেল থেকেই নিতে হবে|

## পার্ট ৬: সবশেষে — একটা একলাইন ফরমুলা মনে রাখো

> **রিকার্সিভ ফাংশনটা দেখো: স্টেট কী, বেস কেস কী, রিকারেন্স কী, কোন দিকে ডিপেন্ড করে।** **তারপর অ্যারে বানাও (স্টেট অনুযায়ী), বেস কেস বসাও, রিকারেন্স অনুযায়ী লুপ চালাও (ডিপেন্ডেন্সি অনুযায়ী দিক ঠিক করে), শেষে অরিজিনাল কলের জায়গার উত্তর প্রিন্ট করো।**

এই ৫-ধাপের প্রসেসটা **যেকোনো** রিকার্সিভ DP প্রব্লেমে অ্যাপ্লাই করা যায় — ফিবোনাচ্চি, কয়েন কম্বিনেশনস, ন্যাপস্যাক, LCS, সবকিছুতে একই প্রসেস।
