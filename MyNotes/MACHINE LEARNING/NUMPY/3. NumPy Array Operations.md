## সংজ্ঞা (Definition)

NumPy array-এর উপর বিভিন্ন mathematical, structural আর manipulation operation — element-wise math থেকে শুরু করে array জোড়া লাগানো/ভাঙা পর্যন্ত। এই operations গুলোই NumPy-কে দ্রুত ও powerful করে তোলে (loop ছাড়াই বড় ডেটার উপর কাজ করা যায়)।

---

## 1. Arithmetic Operations

```python
import numpy as np

a = np.array([1, 2, 3, 4])
b = np.array([10, 20, 30, 40])

print(a + b)     # [11 22 33 44]
print(a - b)     # [ -9 -18 -27 -36]
print(a * b)     # [10 40 90 160]
print(a / b)     # [0.1 0.1 0.1 0.1]
print(a ** 2)    # [1 4 9 16]
print(a % 2)     # [1 0 1 0]
```

**মূল কথা:** সব operation **element-wise** — মানে দুই array-এর একই ইনডেক্সের element-গুলো নিজেদের মধ্যে operation করে। Python list-এ `+` করলে concatenate হয়, কিন্তু NumPy array-এ `+` করলে যোগ হয় — এই পার্থক্য মনে রাখা জরুরি।

---

## 2. Broadcasting

ভিন্ন shape-এর array-এর মধ্যে operation করার নিয়ম — ছোট array-কে "stretch" করে বড় array-এর shape-এ ফিট করানো হয় (আসলে মেমোরিতে কপি হয় না, শুধু logic-এ broadcast হয়)।

```python
arr = np.array([[1, 2, 3],
                 [4, 5, 6]])

# একটা scalar-এর সাথে broadcasting
print(arr + 10)
# [[11 12 13]
#  [14 15 16]]

# একটা 1D array-এর সাথে broadcasting (shape মিলতে হবে column অনুযায়ী)
row = np.array([10, 20, 30])
print(arr + row)
# [[11 22 33]
#  [14 25 36]]
```

**নিয়ম:** দুই array-এর shape ডান দিক থেকে তুলনা করা হয়। প্রতিটা dimension-এ হয় সমান হতে হবে, নয়তো একটার সাইজ 1 হতে হবে।

**মূল কথা:** Broadcasting-এর কারণে loop লিখে element-by-element operation করতে হয় না — এটাই NumPy-এর speed-এর মূল রহস্য (এটাকে **Vectorization**ও বলে)।

---

## 3. Deep vs Shallow Copy

```python
arr = np.array([1, 2, 3, 4])

# Shallow copy / View — মেমোরি শেয়ার করে
view_arr = arr.view()
view_arr[0] = 100
print(arr)          # [100   2   3   4]  -> মূল array বদলে গেছে

# Deep copy — সম্পূর্ণ আলাদা মেমোরি
copy_arr = arr.copy()
copy_arr[0] = 999
print(arr)          # [100   2   3   4]  -> মূল array অপরিবর্তিত
```

**মূল কথা:** এইটা তোমার আগের Indexing/Slicing note-এর "View vs Copy" concept-এরই বিস্তৃত রূপ। `.view()` = shallow copy (নতুন object কিন্তু একই ডেটা মেমোরি), `.copy()` = deep copy (সম্পূর্ণ independent)। Slicing-ও ডিফল্টে shallow copy/view রিটার্ন করে।

## 4. Matrix Operations

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

# Element-wise multiplication (এটা matrix multiplication না!)
print(A * B)
# [[ 5 12]
#  [21 32]]

# আসল Matrix multiplication (dot product)
print(A @ B)                # অথবা np.matmul(A, B) অথবা np.dot(A, B)
# [[19 22]
#  [43 50]]

# Transpose
print(A.T)
# [[1 3]
#  [2 4]]

# Determinant, Inverse (linalg module)
print(np.linalg.det(A))     # -2.0
print(np.linalg.inv(A))     # inverse matrix
```

**মূল কথা:** `*` element-wise multiplication, কিন্তু `@` বা `np.dot()` হলো real matrix multiplication — এই দুইটা গুলিয়ে ফেলা খুব common ভুল। Linear regression-এর মতো ML অ্যালগরিদমের ভিতরে matrix multiplication-ই মূলত চলে।

## 5. Stacking Arrays

একাধিক array-কে একসাথে জোড়া দেওয়া।

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# Vertical stack (নতুন row হিসেবে জোড়া)
print(np.vstack((a, b)))
# [[1 2 3]
#  [4 5 6]]

# Horizontal stack (পাশাপাশি জোড়া)
print(np.hstack((a, b)))
# [1 2 3 4 5 6]

# Column stack (প্রতিটা 1D array একটা column হয়ে যায়)
print(np.column_stack((a, b)))
# [[1 4]
#  [2 5]
#  [3 6]]

# নির্দিষ্ট axis বরাবর জোড়া (concatenate)
print(np.concatenate((a, b)))
# [1 2 3 4 5 6]
```

**মূল কথা:** `vstack` = নিচে/উপরে জোড়া (row বাড়ে), `hstack` = পাশাপাশি জোড়া (1D array-গুলো একটাই লম্বা row-তে মিশে যায়), `concatenate` সাধারণভাবে যেকোনো axis-এ জোড়া দিতে পারে।

**⚠️ hstack vs column_stack (গুরুত্বপূর্ণ পার্থক্য):** 1D array-এর ক্ষেত্রে এই দুইটা সম্পূর্ণ ভিন্ন ফলাফল দেয়।

- `hstack((a, b))` → `[1 2 3 4 5 6]` (একটা লম্বা 1D array)
- `column_stack((a, b))` → প্রতিটা 1D array-কে একটা column হিসেবে treat করে পাশাপাশি বসায়, ফলে 2D array তৈরি হয়

এটা তখন কাজে লাগে যখন আলাদা আলাদা feature (প্রতিটা 1D array আকারে) থেকে একটা dataset-এর মতো 2D matrix বানাতে চাও।

## 6. Splitting Arrays

একটা array-কে ভাগ করে একাধিক ছোট array বানানো।

```python
arr = np.array([1, 2, 3, 4, 5, 6])

# সমান ৩ ভাগে ভাগ করা
print(np.split(arr, 3))
# [array([1, 2]), array([3, 4]), array([5, 6])]

arr2d = np.array([[1, 2, 3, 4],
                   [5, 6, 7, 8]])

# Vertical split (row অনুযায়ী ভাগ)
print(np.vsplit(arr2d, 2))

# Horizontal split (column অনুযায়ী ভাগ)
print(np.hsplit(arr2d, 2))
```

**মূল কথা:** `split()`-এর জন্য array-টা সমান ভাগে ভাগ হতে হবে, নাহলে error দেবে (অসমান ভাগের জন্য `array_split()` ব্যবহার করতে হয়)।

## 7. (Bonus — কোর্সে না থাকলেও শেখা জরুরি) Universal Functions (ufuncs)

```python
arr = np.array([1, 4, 9, 16])

print(np.sqrt(arr))     # [1. 2. 3. 4.]
print(np.exp(arr))      # e^x প্রতিটা element-এ
print(np.log(arr))      # natural log
print(np.sin(arr))      # trigonometric
print(np.abs([-1, -2, 3]))   # [1 2 3]
```

**মূল কথা:** এগুলো element-wise math function, লুপ ছাড়াই পুরো array-তে apply হয়।

## 8. (Bonus) Set Operations ও Sorting

```python
a = np.array([1, 2, 2, 3, 4, 4, 5])

print(np.unique(a))              # [1 2 3 4 5] -> ডুপ্লিকেট বাদ

x = np.array([1, 2, 3])
y = np.array([2, 3, 4])
print(np.intersect1d(x, y))      # [2 3] -> কমন এলিমেন্ট
print(np.union1d(x, y))          # [1 2 3 4]

arr = np.array([3, 1, 4, 1, 5])
print(np.sort(arr))              # [1 1 3 4 5]
print(np.argsort(arr))           # sort করলে কোন ইনডেক্স কোথায় যাবে
```

**মূল কথা:** `unique()` EDA-তে খুব কাজে লাগে (কোনো কলামে কতগুলো distinct value আছে দেখতে), `argsort()` কাজে লাগে যখন sort করা মানের আসল ইনডেক্স জানা দরকার হয়।

|Category|Function/Operator|
|---|---|
|Arithmetic|`+ - * / ** %` (element-wise)|

## এক লাইনে মনে রাখো

> `*` = element-wise, `@`/`np.dot()` = real matrix multiplication। `.view()` = shallow (মেমোরি শেয়ার), `.copy()` = deep (independent)। এই দুইটা গুলিয়ে ফেললেই bug হবে।
