## সংজ্ঞা (Definition)

একটা মেশিন লার্নিং মডেল বানাতে গেলে সাধারণত ১১টা ধাপ অনুসরণ করা হয় — শুরু হয় সমস্যা বোঝা দিয়ে, শেষ হয় মডেল validate করে।

```
Problem Definition → Data Collection → EDA → Preprocessing
→ Feature Selection/Engineering → Split Dataset → Model Selection
→ Training → Evaluation → Hyperparameter Tuning → Testing/Validation
```

---

## পুরো Pipeline

### ধাপ ১ — [[Problem Definition]]

কী সমস্যা সমাধান করতে চাচ্ছি সেটা স্পষ্ট করা। Classification নাকি Regression? Business goal কী?

### ধাপ ২ — [[Data Collection]]

দরকারি ডেটা জোগাড় করা — CSV file, database, API, web scraping ইত্যাদি সোর্স থেকে।

### ধাপ ৩ — [[EDA]]

ডেটা বোঝা, দেখা, pattern ও distribution বিশ্লেষণ করা। মডেল বানানোর আগে ডেটার সাথে "পরিচিত হওয়ার" ধাপ।

### ধাপ ৪ — [[Data Preprocessing]] / [[Data Cleaning]]

Missing value handle করা, duplicate remove করা, outlier ঠিক করা, ডেটাকে মডেলের জন্য প্রস্তুত করা।

### ধাপ ৫ — [[Feature Selection]] & [[Feature Engineering]]

কোন ফিচার গুরুত্বপূর্ণ সেটা বাছাই করা, আর দরকার হলে নতুন ফিচার তৈরি করা।

### ধাপ ৬ — [[Train Test Split]]

ডেটাসেটকে Train/Test (বা Train/Validation/Test) ভাগে ভাগ করা, যাতে মডেলকে unseen ডেটায় যাচাই করা যায়।

### ধাপ ৭ — [[Model Selection]]

সমস্যার ধরন অনুযায়ী সঠিক অ্যালগরিদম বেছে নেওয়া (Linear Regression, Decision Tree, Random Forest, SVM ইত্যাদি)।

### ধাপ ৮ — [[Model Training]]

Train ডেটা দিয়ে মডেলকে pattern শেখানো।

### ধাপ ৯ — [[Model Evaluation]]

মডেল কতটা ভালো কাজ করছে সেটা মেট্রিক দিয়ে মাপা — Accuracy, Precision, Recall, RMSE ইত্যাদি।

### ধাপ ১০ — [[Hyperparameter Tuning]]

মডেলের সেটিংস (parameters) ঠিক করে performance আরও ভালো করা — Grid Search, Random Search ইত্যাদি।

### ধাপ ১১ — [[Model Testing]] / [[Model Validation]]

চূড়ান্তভাবে সম্পূর্ণ নতুন/unseen ডেটায় মডেল কেমন পারফর্ম করে সেটা যাচাই করা।

## গুরুত্বপূর্ণ পার্থক্য মনে রাখো

|ধাপ|কী করা হয়|
|---|---|
|EDA|শুধু দেখা, বোঝা, বিশ্লেষণ করা (analysis)|
|Preprocessing/Cleaning|সমস্যাগুলো fix করা (action)|

বাস্তবে এই দুইটা প্রায়ই একসাথে মিশিয়ে করা হয়, কিন্তু strict pipeline অনুযায়ী আলাদা ধাপ।
