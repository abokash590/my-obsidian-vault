## সংজ্ঞা (Definition)

EDA হলো ডেটাসেট নিয়ে কাজ শুরু করার আগে সেই ডেটাকে ভালোভাবে বোঝা, দেখা আর বিশ্লেষণ করার প্রক্রিয়া — কোনো মডেল বানানোর আগেই। উদ্দেশ্য হলো ডেটার **pattern, anomaly, relationship, আর quality** বুঝে ফেলা, যাতে পরে সঠিক preprocessing আর মডেল বেছে নেওয়া যায়।

> "Garbage in, garbage out" — ডেটা না বুঝে মডেল বানালে রেজাল্টও ভুল হবে। তাই EDA হলো ML pipeline-এর সবচেয়ে গুরুত্বপূর্ণ প্রথম ধাপ।

---

## কেন EDA করা হয়

- ডেটাসেটে কী কী কলাম/ফিচার আছে, তাদের টাইপ কী (numeric, categorical, date ইত্যাদি) বোঝা
- Missing value, duplicate, outlier খুঁজে বের করা
- ফিচারগুলোর মধ্যে সম্পর্ক (correlation) বোঝা
- ডেটার distribution/shape দেখা (normal, skewed ইত্যাদি)
- কোন ফিচার গুরুত্বপূর্ণ আর কোনটা বাদ দেওয়া যায় সেটার প্রাথমিক ধারণা পাওয়া
- ভুল assumption নিয়ে মডেল বানানো থেকে বাঁচা

## EDA-এর ধাপসমূহ

### ১. ডেটা লোড করা ও প্রাথমিক ধারণা নেওয়া

```python
import pandas as pd

df = pd.read_csv('data.csv')
df.head()          # প্রথম কয়েকটা row দেখা
df.shape            # কতটা row, column আছে
df.info()           # কলামের ডেটাটাইপ, null count
df.describe()       # numeric কলামের statistics (mean, std, min, max)
```

### ২. Missing Value চেক করা

```python
df.isnull().sum()                    # প্রতিটা কলামে কতগুলো missing value
df.isnull().sum() / len(df) * 100    # percentage হিসেবে
```

**হ্যান্ডলিং অপশন:**

- Row/column drop করা (যদি missing খুব বেশি হয়)
- Mean/Median/Mode দিয়ে fill করা (Imputation)
- Forward fill / Backward fill (time series-এর জন্য)

### ৩. Duplicate ডেটা চেক করা


```python
df.duplicated().sum()
df.drop_duplicates(inplace=True)
```

### ৪. Univariate Analysis (একটা ফিচার নিয়ে বিশ্লেষণ)

একটা কলামের distribution/shape দেখা।

- **Numeric ফিচার:** Histogram, Box Plot, KDE Plot
- **Categorical ফিচার:** Count Plot, Pie Chart

```python
import seaborn as sns
import matplotlib.pyplot as plt

sns.histplot(df['age'])
sns.boxplot(df['salary'])
sns.countplot(df['gender'])
```

### ৫. Bivariate/Multivariate Analysis (দুই বা তার বেশি ফিচারের সম্পর্ক)

- **Numeric vs Numeric:** Scatter Plot, Correlation Heatmap
- **Categorical vs Numeric:** Box Plot, Bar Plot (group by)
- **Categorical vs Categorical:** Crosstab, Stacked Bar Chart

```python
sns.scatterplot(x='age', y='salary', data=df)
sns.heatmap(df.corr(), annot=True, cmap='coolwarm')
sns.boxplot(x='department', y='salary', data=df)
```

### ৬. Outlier Detection (অস্বাভাবিক ডেটা খোঁজা)

Outlier মানে এমন ডেটা পয়েন্ট যা বাকি ডেটা থেকে অনেক আলাদা — এটা মডেলকে বিভ্রান্ত করতে পারে।

- **Box Plot** দিয়ে visual-এ দেখা
- **IQR Method** (Interquartile Range):


```python
Q1 = df['salary'].quantile(0.25)
Q3 = df['salary'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
outliers = df[(df['salary'] < lower_bound) | (df['salary'] > upper_bound)]
```

- **Z-Score Method:** যেসব পয়েন্টের Z-score 3-এর বেশি বা -3-এর কম, তারা outlier হিসেবে ধরা হয়

### ৭. Correlation Analysis

কোন ফিচার একটা আরেকটার সাথে কতটা সম্পর্কিত সেটা বোঝা — feature selection-এর জন্য দরকারি।

```python
correlation_matrix = df.corr()
sns.heatmap(correlation_matrix, annot=True)
```

- +1 → পুরোপুরি positive correlation
- -1 → পুরোপুরি negative correlation
- 0 → কোনো correlation নেই

### ৮. Distribution ও Skewness চেক করা

ডেটা normal distribution-এ আছে নাকি skewed (একদিকে হেলে আছে), সেটা বোঝা জরুরি — কারণ অনেক ML অ্যালগরিদম normal distribution assume করে।

```python
df['salary'].skew()
sns.histplot(df['salary'], kde=True)
```

## EDA-এর সময় নিজেকে যে প্রশ্নগুলো করবে

- ডেটাসেটে কতগুলো row/column আছে?
- কোন কোন কলাম categorical, কোনগুলো numeric?
- কোথাও missing value বা duplicate আছে কিনা?
- Target variable-এর distribution কেমন (balanced নাকি imbalanced)?
- কোন ফিচারগুলো target-এর সাথে বেশি correlated?
- Outlier আছে কিনা, থাকলে সেটা genuine নাকি ডেটা এন্ট্রি error?
- ফিচারগুলোর scale একরকম নাকি অনেক তফাত (normalization লাগবে কিনা)?

## সংক্ষেপে টেবিল

|ধাপ|উদ্দেশ্য|Tool/Method|

|Correlation|ফিচারদের মধ্যে সম্পর্ক|`.corr()`, Heatmap|
