## সংজ্ঞা (Definition)

Pandas Series হলো **1-dimensional labeled array** — একটা single column-এর ডেটা, যার প্রতিটা value-এর সাথে একটা করে **index (label)** যুক্ত থাকে। NumPy array-এর "উন্নত ভার্সন" হিসেবে ভাবা যায় — position-এর পাশাপাশি নাম (label) দিয়েও ডেটা access করা যায়।

- NumPy array → শুধু position দিয়ে access (0, 1, 2...)
- Pandas Series → position + custom label দুইটা দিয়েই access

Pandas DataFrame আসলে একাধিক Series পাশাপাশি জোড়া লাগিয়ে বানানো — তাই Series ভালো বুঝলে DataFrame বুঝতে সুবিধা হবে।

---
## 1. Series তৈরি করা

`import pandas as pd`

| **Syntax**                                     | **Description**                                    |
| --------------------------------------------------- | ---------------------------------------------------------- |
| `pd.Series([10, 20, 30, 40])`                       | List থেকে তৈরি — index ডিফল্টে 0, 1, 2... হয়ে যায়          |
| `pd.Series([10, 20, 30], index=['a', 'b', 'c'])`    | Custom label/index দিয়ে তৈরি                               |
| `pd.Series({'math': 90, 'physics': 85})`            | Dictionary থেকে তৈরি — key নিজে থেকেই index হয়ে যায়        |
| `pd.Series(5, index=['x', 'y', 'z'])`               | Scalar value দিয়ে তৈরি — একই value সব index-এ বসে           |
## মূল কথা
`index` না দিলে ডিফল্টে 0, 1, 2... হয়ে যায়। Dictionary থেকে বানালে key নিজে থেকেই index হয়ে যায়।

## 2. Series-এর Attributes

| **Syntax**       | **Description**                                     |
| ---------------------- | ------------------------------------------------------------ |
| `s.values`             | শুধু value-গুলো, NumPy array হিসেবে রিটার্ন করে              |
| `s.index`               | Index/label-গুলোর list                                       |
| `s.dtype`               | Data type (int64, float64...)                                |
| `s.shape`               | Shape — `(n,)` আকারে                                          |
| `s.size`                | মোট element সংখ্যা                                            |
| `s.name`                | Series-এর নাম — DataFrame থেকে column আনলে column name বসে   |
## মূল কথা
`.values` দিলে আসলে একটা NumPy array পাওয়া যায় — এইখানেই Pandas আর NumPy-এর connection বোঝা যায়।

---
## 3. Indexing ও Accessing Values

| **Syntax**              | **Description**                                       |
| ---------------------------- | ----------------------------------------------------------- |
| `s['a']`                     | Label দিয়ে সরাসরি access                                     |
| `s[['a', 'c']]`               | একাধিক label একসাথে access                                   |
| `s.iloc[0]`                  | Position (0,1,2...) দিয়ে access                              |
| `s.iloc[1:3]`                | Position দিয়ে slicing — শেষটা exclude হয় (NumPy-এর মতো)     |
| `s.loc['a']`                 | Label দিয়ে explicit access (recommended)                     |
| `s.loc['a':'c']`             | Label দিয়ে slicing — শেষটাও **include** হয়                  |

**⚠️ গুরুত্বপূর্ণ পার্থক্য:**

| Method      | কীভাবে access করে       | Slicing-এ শেষ ইনডেক্স                     |
| ----------- | --------------------------- | ---------------------------------------------- |
| `.loc[]`    | label/index name দিয়ে       | included (যেমন `'a':'c'` মানে a,b,c সবই)       |
| `.iloc[]`   | position (0,1,2...) দিয়ে    | excluded (NumPy-এর মতো)                        |
## মূল কথা
সরাসরি `s['a']` কাজ করলেও, ambiguity এড়াতে সবসময় `.loc[]` (label) আর `.iloc[]` (position) ব্যবহার করা ভালো অভ্যাস — বিশেষ করে যখন index সংখ্যা দিয়েও হতে পারে।

## 4. Boolean Indexing / Filtering

| **Syntax**                    | **Description**                                |
| ---------------------------------- | -------------------------------------------------------- |
| `s[s > 25]`                        | শর্ত মেনে চলা value-গুলো বের করা                          |
| `s[(s > 10) & (s < 50)]`           | একাধিক শর্ত একসাথে (`&` = and, `\|` = or)                |

## 5. Basic Operations & Statistics

| **Syntax**       | **Description**                                     |
| ---------------------- | ------------------------------------------------------------ |
| `s.sum()`              | সব element-এর যোগফল                                          |
| `s.mean()`             | গড়                                                            |
| `s.median()`           | মধ্যমা                                                        |
| `s.std()`              | Standard deviation                                            |
| `s.min()` / `s.max()`  | সর্বনিম্ন / সর্বোচ্চ মান                                     |
| `s.describe()`         | সব statistics একসাথে (count, mean, std, min, max, quartiles) |
| `s + 5`                | প্রতিটা element-এ 5 যোগ (broadcasting, NumPy-এর মতোই)        |
| `s * 2`                | প্রতিটা element 2 গুণ                                         |
## মূল কথা
Arithmetic operation ও statistics NumPy-এর মতোই কাজ করে — কারণ Pandas ভিতরে NumPy-ই ব্যবহার করে।

---

## 6. Useful Methods

| **Syntax**                       | **Description**                              |
| ------------------------------------- | ------------------------------------------------- |
| `s.isnull()`                          | কোথায় missing value (`NaN`) আছে — True/False মাস্ক |
| `s.notnull()`                          | `isnull()`-এর উল্টো                                |
| `s.dropna()`                          | Missing value বাদ দিয়ে নতুন Series                 |
| `s.fillna(0)`                         | Missing value-কে 0 দিয়ে fill করা                    |
| `s.unique()`                          | Distinct value-গুলোর list                          |
| `s.value_counts()`                    | প্রতিটা value কতবার আছে (frequency count)          |
| `s.sort_values()`                     | Value অনুযায়ী sort                                 |
| `s.sort_index()`                      | Index অনুযায়ী sort                                 |
| `s.apply(lambda x: x * 2)`            | প্রতিটা element-এ function apply করা               |
## মূল কথা
`value_counts()` আর `isnull()`/`fillna()` — এই দুইটা EDA আর ডেটা ক্লিনিং-এ সবচেয়ে বেশি ব্যবহার হয়।

---

## এক লাইনে মনে রাখো
> Series = label + value-এর জোড়া (এক কলামের ডেটা)। `.loc[]` label দিয়ে, `.iloc[]` position দিয়ে access করে — এই দুইটা গুলালে bug হবে।
