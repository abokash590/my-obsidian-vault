	## সংজ্ঞা (Definition)

Missing Data মানে ডেটাসেটে এমন জায়গা যেখানে value নেই — কোনো কারণে সেই তথ্য রেকর্ড হয়নি, হারিয়ে গেছে, বা প্রযোজ্য না। Pandas-এ এটাকে সাধারণত `NaN` (Not a Number) দিয়ে represent করা হয়। ML মডেল সরাসরি `NaN` নিয়ে কাজ করতে পারে না, তাই [[EDA]]-এর পরপরই এটা handle করা লাগে।

**Missing data কেন হয়:**

- ডেটা কালেকশনের সময় কেউ উত্তর দেয়নি (যেমন survey-তে খালি রাখা)
- Sensor/system error-এর কারণে value রেকর্ড হয়নি
- ডেটা merge করার সময় কোনো id মেলেনি
- মানুষ manual entry করার সময় ভুলে বাদ দিয়েছে

---

## Part 1 — Finding (মিসিং ডেটা খুঁজে বের করা)

| **Syntax**                            | **Description**                                                  |
| ------------------------------------- | ---------------------------------------------------------------- |
| `df.isnull()` / `df.isna()`           | কোথায় missing value আছে — True/False টেবিল (দুইটাই একই কাজ করে) |
| `df.isnull().sum()`                   | প্রতিটা column-এ কতগুলো missing value                            |
| `df.isnull().sum().sum()`             | পুরো dataset-এ মোট কতগুলো missing value                          |
| `(df.isnull().sum() / len(df)) * 100` | প্রতিটা column-এ missing value-এর percentage                     |
| `df.isnull().any(axis=1)`             | কোন row-তে অন্তত একটা missing আছে কিনা                           |
| `df[df.isnull().any(axis=1)]`         | শুধু missing value থাকা row-গুলো দেখা                            |
| `df[df['age'].isnull()]`              | নির্দিষ্ট column-এ missing আছে এমন row                           |
| `df.notnull()`                        | উল্টো — কোথায় missing নেই                                       |

## মূল কথা

`isnull().sum()` সবচেয়ে বেশি ব্যবহৃত command — এক লাইনে বলে দেয় কোন column-এ কতটা সমস্যা আছে। EDA-এর একদম শুরুতেই এটা run করা উচিত।

---

## Part 2 — Removing (মিসিং ডেটা বাদ দেওয়া)

|**Syntax**|**Description**|
|---|---|
|`df.dropna()`|যেকোনো row-তে একটাও missing থাকলে সেই row বাদ|
|`df.dropna(how='all')`|সব value missing হলে তবেই row বাদ (কম strict)|
|`df.dropna(subset=['age'])`|নির্দিষ্ট column-এ missing থাকলেই সেই row বাদ|
|`df.dropna(axis=1)`|Column বাদ দেওয়া (row না)|
|`df.dropna(thresh=2)`|কমপক্ষে এতগুলো non-null value না থাকলে row বাদ (যেমন `thresh=2`)|
|`df.dropna(inplace=True)`|আসল DataFrame-এই পরিবর্তন সেভ করা|

**কখন Remove করা উচিত:**

- Missing value খুব কম হলে (যেমন ১-২%) — row বাদ দিলে তেমন ক্ষতি হয় না
- পুরো row-ই যদি অপ্রয়োজনীয় হয়ে যায় (বেশিরভাগ column missing)
- খুব বড় dataset হলে, কিছু row হারালে সমস্যা হয় না

**কখন Remove করা উচিত না:**

- Missing value অনেক বেশি হলে (৩০-৪০%+) — `dropna()` করলে valuable ডেটা হারিয়ে যাবে
- Dataset ছোট হলে — প্রতিটা row মূল্যবান

## মূল কথা

`dropna()` সবচেয়ে সহজ সমাধান, কিন্তু সবসময় সঠিক না — ডেটা হারানোর trade-off আছে।

---

## Part 3 — Filling (মিসিং ডেটা পূরণ করা / Imputation)

|**Syntax**|**Description**|
|---|---|
|`df.fillna(0)`|একটা fixed value দিয়ে fill|
|`df['city'].fillna('Unknown', inplace=True)`|নির্দিষ্ট column-এ fixed value দিয়ে fill|
|`df['age'].fillna(df['age'].mean(), inplace=True)`|Mean দিয়ে fill (numeric column-এর জন্য common)|
|`df['age'].fillna(df['age'].median(), inplace=True)`|Median দিয়ে fill (outlier থাকলে mean-এর চেয়ে ভালো choice)|
|`df['city'].fillna(df['city'].mode()[0], inplace=True)`|Mode দিয়ে fill (categorical column-এর জন্য)|
|`df.fillna(method='ffill')`|Forward fill — আগের value দিয়ে fill (time series-এ বেশি ব্যবহৃত)|
|`df.fillna(method='bfill')`|Backward fill — পরের value দিয়ে fill|
|`df.fillna({'age': df['age'].mean(), 'city': 'Unknown'})`|প্রতিটা column-এ আলাদা আলাদা value দিয়ে fill|
|`df['age'].interpolate(method='linear', inplace=True)`|Interpolation — আশেপাশের value দিয়ে অনুমান করে fill|

**কোন Method কখন ব্যবহার করবে:**

|Method|কখন ব্যবহার করবে|
|---|---|
|**Mean**|Numeric column, distribution normal (outlier কম) হলে|
|**Median**|Numeric column, outlier/skewed distribution থাকলে|
|**Mode**|Categorical column (সবচেয়ে বেশি repeat হওয়া value)|
|**Fixed value** (যেমন `'Unknown'`, `0`)|যখন missing হওয়াটাই একটা অর্থবহ তথ্য|
|**Forward/Backward fill**|Time series ডেটা, যেখানে ক্রমান্বয়ে ডেটা আসে|
|**Interpolation**|Numeric, trend/pattern থাকা ডেটা (যেমন তাপমাত্রা, স্টক প্রাইস)|

## মূল কথা

কোনো একটা "সবসময় সঠিক" method নেই — ডেটার ধরন আর missing হওয়ার কারণ বুঝে method বাছাই করতে হয়। Mean/Median/Mode হলো সবচেয়ে সাধারণ ও দ্রুত সমাধান, কিন্তু Time Series-এ Forward Fill বা Interpolation বেশি accurate হয়।

---

## Advanced — Missing Indicator যোগ করা

কখনো কখনো "কোথায় missing ছিল" এই তথ্যটাও মডেলের জন্য কাজে লাগতে পারে (হয়তো missing হওয়াটাই একটা pattern)।

| **Syntax**                                               | **Description**                                             |
| -------------------------------------------------------- | ----------------------------------------------------------- |
| `df['age_was_missing'] = df['age'].isnull().astype(int)` | Missing ছিল কিনা সেটা একটা নতুন boolean (0/1) column-এ রাখা |
| `df['age'].fillna(df['age'].mean(), inplace=True)`       | এরপর আসল value normally fill করা                            |

## মূল কথা

মূল value fill করার পাশাপাশি একটা নতুন boolean column রাখলে, "এই row-এ আগে missing ছিল" এই তথ্যটাও মডেল ব্যবহার করতে পারবে।

## Decision Flow — কী করবো?

```
Missing value কতটা?
├── খুব কম (< 5%) এবং random?
│   └── dropna() করে ফেলো
│
├── মাঝারি (5-30%)?
│   ├── Numeric column → mean/median দিয়ে fill
│   └── Categorical column → mode/'Unknown' দিয়ে fill
│
└── অনেক বেশি (> 30-40%)?
    ├── সেই column-ই বাদ দেওয়ার কথা ভাবো, অথবা
    └── advanced imputation (KNN Imputer, ML-based) বিবেচনা করো
```

---

## এক লাইনে মনে রাখো

> Missing data নিয়ে প্রথমে **খুঁজে বের করো** (`isnull().sum()`), তারপর সিদ্ধান্ত নাও — **কম হলে বাদ দাও, বেশি হলে বুঝে-শুনে fill করো**। Outlier থাকলে mean না, median ব্যবহার করো।
