## সংজ্ঞা (Definition)

DataFrame হলো **2-dimensional labeled data structure** — row আর column দুইটাই থাকে, ঠিক Excel sheet বা SQL টেবিলের মতো। প্রতিটা column আসলে একটা [[Pandas Series]] — একাধিক Series পাশাপাশি জোড়া লাগিয়েই DataFrame তৈরি হয়।

> DataFrame = একাধিক Series পাশাপাশি (প্রতিটা column একটা Series)

এটাই Pandas-এর সবচেয়ে বেশি ব্যবহৃত structure — বাস্তবে প্রায় সব ডেটা DataFrame আকারেই handle করা হয়।

---

## 1. DataFrame তৈরি করা

`import pandas as pd`

|**Syntax**|**Description**|
|---|---|
|`pd.DataFrame({'name': [...], 'age': [...]})`|Dictionary থেকে তৈরি (key → column name, value list → data) — সবচেয়ে common পদ্ধতি|
|`pd.DataFrame([[1, 'A'], [2, 'B']], columns=[...])`|List of lists থেকে, column নাম আলাদাভাবে দিয়ে|
|`pd.read_csv('data.csv')`|CSV ফাইল থেকে — বাস্তবে সবচেয়ে বেশি ব্যবহৃত|
|`pd.read_excel('data.xlsx')`|Excel ফাইল থেকে|

## মূল কথা

বাস্তব প্রজেক্টে বেশিরভাগ সময় `pd.read_csv()` দিয়েই DataFrame বানানো হয় — dictionary/list দিয়ে বানানো সাধারণত practice বা ছোট ডেটার জন্য।

## 2. প্রাথমিক পর্যবেক্ষণ (Overview)

|**Syntax**|**Description**|
|---|---|
|`df.head()`|প্রথম ৫টা row|
|`df.tail(n)`|শেষ n টা row|
|`df.shape`|`(rows, columns)`|
|`df.columns`|কলামের নামের list|

## মূল কথা

[[EDA]]-তে যা করা হয় তার ভিত্তি এগুলোই — নতুন কোনো ডেটাসেট পেলে প্রথমেই এগুলো run করে দেখা উচিত।

## 3. Column নিয়ে কাজ করা

|**Syntax**|**Description**|
|---|---|
|`df['name']`|একটা column select — **Series** রিটার্ন করে (1D)|
|`df.name`|একইভাবে কাজ করে, কিন্তু column name-এ space/special char থাকলে সমস্যা হয়|
|`df[['name', 'age']]`|একাধিক column select — **DataFrame** রিটার্ন করে (2D)|
|`df['is_adult'] = df['age'] >= 18`|নতুন column যোগ করা|
|`df.rename(columns={'name': 'full_name'}, inplace=True)`|Column rename করা|
|`df.drop('city', axis=1, inplace=True)`|Column বাদ দেওয়া|

**⚠️ গুরুত্বপূর্ণ:** `df['col']` → Series, `df[['col']]` → DataFrame (একটা column হলেও)। ডবল bracket দিলে DataFrame structure বজায় থাকে — এই একটা bracket-এর পার্থক্যেই structure বদলে যায়।

---

## 4. Row নিয়ে কাজ করা (Indexing)

|**Syntax**|**Description**|
|---|---|
|`df.iloc[0]`|Position অনুযায়ী প্রথম row|
|`df.iloc[0:3]`|Position দিয়ে slicing — শেষটা excluded|
|`df.iloc[0, 1]`|Row 0, column 1-এর নির্দিষ্ট value|
|`df.loc[0]`|Label অনুযায়ী index 0-এর row|
|`df.loc[0:2]`|Label দিয়ে slicing — শেষটাও **included**|
|`df.loc[0, 'name']`|Row 0, column `'name'`-এর নির্দিষ্ট value|
|`df.loc[0:2, ['name', 'age']]`|একাধিক row-column একসাথে select|

## মূল কথা

[[Pandas Series]] note-এ বলা `.loc` vs `.iloc`-এর নিয়ম DataFrame-এও একই — `.loc` label-based (শেষটাও included), `.iloc` position-based (শেষটা excluded)।

---

## 5. Filtering (Boolean Indexing)

|**Syntax**|**Description**|
|---|---|
|`df[df['age'] > 21]`|একটা শর্ত মেনে চলা row বের করা|
|`df[(df['age'] > 20) & (df['city'] == 'Dhaka')]`|একাধিক শর্ত একসাথে (`&`/`\|`, Python-এর `and`/`or` না)|
|`df.query('age > 21 and city == "Dhaka"')`|`.query()` দিয়ে একই কাজ, কিন্তু বেশি readable|
|`df[df['city'].isin(['Dhaka', 'Chittagong'])]`|কোনো column-এর value একটা list-এর মধ্যে আছে কিনা চেক|

## মূল কথা

ML/EDA-তে ডেটা filter করাটা সবচেয়ে বেশি ব্যবহৃত operation — নির্দিষ্ট condition-এর row বের করে subset নিয়ে কাজ করা।

---

## 6. Missing Value Handling

|**Syntax**|**Description**|
|---|---|
|`df.isnull().sum()`|প্রতিটা column-এ কতগুলো missing value আছে|
|`df.dropna()`|Missing value থাকা row বাদ|
|`df.dropna(axis=1)`|Missing value থাকা column বাদ|
|`df.fillna(0)`|সব missing value 0 দিয়ে fill|
|`df.fillna(df['age'].mean())`|Mean দিয়ে fill|
|`df['age'].fillna(df['age'].median(), inplace=True)`|নির্দিষ্ট column-এ median দিয়ে fill, in-place|

## মূল কথা

এটা [[EDA]]-র "Missing Value" অংশের practical implementation — DataFrame-এর context-এ।

---

## 7. Grouping ও Aggregation

|**Syntax**|**Description**|
|---|---|
|`df.groupby('city')['age'].mean()`|একটা column অনুযায়ী group করে average বের করা|
|`df.groupby('city')['age'].agg(['mean', 'min', 'max', 'count'])`|একাধিক aggregation একসাথে|
|`df.groupby(['city', 'is_adult'])['age'].mean()`|একাধিক column দিয়ে group করা|

## মূল কথা

`groupby()` হলো SQL-এর `GROUP BY`-এর মতো — কোনো category অনুযায়ী ডেটা ভাগ করে তারপর প্রতিটা group-এ calculation করা। EDA-তে pattern বের করার জন্য গুরুত্বপূর্ণ।

## 8. Sorting

|**Syntax**|**Description**|
|---|---|
|`df.sort_values('age')`|`age` অনুযায়ী ascending sort|
|`df.sort_values('age', ascending=False)`|Descending sort|
|`df.sort_values(['city', 'age'])`|একাধিক column অনুযায়ী sort|
|`df.sort_index()`|Index অনুযায়ী sort|

---

## 9. Apply ও Custom Function

|**Syntax**|**Description**|
|---|---|
|`df['age'].apply(lambda x: 'Adult' if x >= 18 else 'Minor')`|একটা column-এর প্রতিটা value-তে function apply করা|
|`df.apply(lambda row: f"{row['name']} is {row['age']}", axis=1)`|পুরো row নিয়ে কাজ করতে হলে `axis=1` দিতে হয়|

---

## 10. Merging / Joining DataFrames

|**Syntax**|**Description**|
|---|---|
|`pd.merge(df1, df2, on='id', how='inner')`|শুধু দুই DataFrame-এ common থাকা `id`-এর row|
|`pd.merge(df1, df2, on='id', how='left')`|`df1`-এর সব row রাখা, না মিললে `NaN`|
|`pd.merge(df1, df2, on='id', how='outer')`|দুই DataFrame-এর সব `id`, না মিললে `NaN`|
|`pd.concat([df1, df2], axis=0)`|নিচে জোড়া লাগানো (row বাড়ে)|
|`pd.concat([df1, df2], axis=1)`|পাশে জোড়া লাগানো (column বাড়ে)|

## মূল কথা

`merge()` SQL-এর JOIN-এর মতো (key column অনুযায়ী মেলানো), `concat()` NumPy-এর `vstack`/`hstack`-এর মতো (শুধু জোড়া লাগানো)।
