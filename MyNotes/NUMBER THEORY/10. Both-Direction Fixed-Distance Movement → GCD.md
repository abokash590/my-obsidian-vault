Move/swap between i, j allowed when |i-j| ∈ {x, y, z, ...}, both directions.
**g = gcd(x, y, z, ...)**

- Reachable positions from i: exactly those ≡ i (mod g) — Bézout's identity.
- Sortable/reachable check: (p_i - i) % g == 0 for all i.

```cpp
int g = x1;
for (int i = 2; i <= k; i++) g = __gcd(g, x_i);
// check (p[i]-i) % g == 0 for all i
```
