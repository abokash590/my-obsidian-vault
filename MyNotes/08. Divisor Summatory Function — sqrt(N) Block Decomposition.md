## Code (C++)

```cpp
#include <bits/stdc++.h>
using namespace std;

long long divisor_summatory_sqrt(long long n) {
    long long D = 0;
    for (long long i = 1, next; i <= n; i = next + 1) {
        long long val = n / i;
        next = n / val;
        D += val * (next - i + 1);
    }return D;
}
int main() {
    long long n;cin >> n;
    cout << divisor_summatory_sqrt(n);
}
```

## Complexity

|Approach|Complexity|
|---|---|
|Naive loop (Σ floor(n/i))|O(N)|
|sqrt block decomposition|**O(√N)**|
